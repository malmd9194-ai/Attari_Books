# 📚 Attari Books

Attari Books is a modern digital library web app where readers can explore, read, and download books seamlessly.

🔗 **Live Website:** [attari-books.vercel.app](https://attari-books.vercel.app)

---

## ✨ Features

- 📖 **Online PDF Reader:** Full-screen responsive PDF reader with page-by-page view.
- 📥 **Free Downloads:** Instant one-click PDF downloads.
- 🔍 **Instant Search:** Fast live search across all available books.
- 👁️ **Live Views & Presence:** Real-time online viewer counter and read-triggered view tracking via Supabase.
- ⭐ **Star Ratings & Comments:** Integrated user reviews synced with Google Sheets.
- 🔐 **Google Sign-In:** Secure authentication powered by Supabase OAuth.
- 📱 **Mobile-Friendly UI:** Clean sliding navigation drawer with support and social links.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **PDF Engine:** PDF.js
- **Database & Auth:** Supabase
- **Reviews & Storage:** Google Apps Script / Google Sheets
- **Hosting & Deployment:** Vercel
