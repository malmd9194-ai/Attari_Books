# Attari Books

Attari Books is a modern digital library web app where readers can explore, read, and download books seamlessly.

🔗 **Live Website:** [attari-books.vercel.app](https://attari-books.vercel.app)

---

## ✨ Key Features

- 📖 **Online PDF Reader:** Clean full-screen PDF reading experience.
- 📥 **Free Downloads:** Instant one-click PDF downloads.
- 🔍 **Instant Search:** Quick title search across the entire library.
- ⭐ **Ratings & Reviews:** Leave star ratings and comments with Google authentication.
- 👁️ **Live Reader Presence:** Real-time online viewer counts.
- 📱 **Responsive Design:** Optimized for mobile phones, tablets, and desktop.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript
- **PDF Engine:** PDF.js
- **Auth & Database:** Supabase
- **Reviews & Storage:** Google Apps Script / Google Sheets
- **Hosting:** Vercel
